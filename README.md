# Reckon（各種計算ツール）

[日本語](#日本語) | [English](#english)

## 日本語

年齢計算・電卓・単位変換など、14種類の計算ツールをまとめたWebツール集です。インストール不要で、PC・スマホの両方で使えます。

入力した内容は送信されず、すべてお使いの端末内で計算されます。

**👉 [今すぐ使う](https://daigorou-addon.github.io/reckon/)**

### ツール一覧

#### 日付・時間

| ツール | 内容 |
| --- | --- |
| 年齢計算 | 生年月日から今の年齢と、次の誕生日までの日数を出す |
| 日付差分計算 | 2つの日付の差、またはN日後・N日前の日付を出す |
| カウントダウン | 配信開始やイベントまでの残り時間を表示する |
| 曜日計算 | 指定した日付の曜日を調べる |
| 時差計算 | 2つの都市の現在時刻と時差を比較する |
| 干支・十二支 | 生まれ年から十二支と干支を調べる |

#### 計算・数学

| ツール | 内容 |
| --- | --- |
| 電卓 | 基本計算と関数電卓モード |
| 割り勘計算 | 端数調整・幹事多めにも対応 |
| パーセント計算 | 割引後の価格や増減率をまとめて計算 |
| 単位変換 | 長さ・重さ・温度・面積・体積を変換 |
| 進数変換 | 2進数・8進数・10進数・16進数・ASCII |
| 二次方程式 | ax²+bx+c=0 の解を求める |

#### 健康

| ツール | 内容 |
| --- | --- |
| BMI計算 | 身長・体重からBMIと適正体重を出す |
| 消費カロリー | 運動の種類・時間から消費カロリーを出す |

## English

Reckon is a collection of 14 calculators, including age, arithmetic, and unit conversion. No installation is required, and it works on both desktop and mobile.

Nothing you enter is sent anywhere. Everything is calculated on your own device.

**👉 [Try it now](https://daigorou-addon.github.io/reckon/)**

### Tools

#### Date & Time

| Tool | Description |
| --- | --- |
| Age Calculator | Get your current age and days until your next birthday |
| Date Difference | Find the difference between two dates, or a date N days away |
| Countdown | Show the time remaining until a stream or event |
| Day of Week | Find what day of the week a date falls on |
| Time Zones | Compare the current time and difference between two cities |
| Chinese Zodiac | Find your Chinese zodiac animal and sexagenary cycle |

#### Math

| Tool | Description |
| --- | --- |
| Calculator | Basic calculator with a scientific mode |
| Split the Bill | Supports rounding adjustment and having the organizer pay more |
| Percentage | Discounted prices, percentage change, and more |
| Unit Converter | Convert length, weight, temperature, area, and volume |
| Base Converter | Binary, octal, decimal, hex, and ASCII |
| Quadratic Equation | Solve for x in ax²+bx+c=0 |

#### Health

| Tool | Description |
| --- | --- |
| BMI Calculator | Get your BMI and healthy weight range from height and weight |
| Calories Burned | Estimate calories burned by activity type and duration |
